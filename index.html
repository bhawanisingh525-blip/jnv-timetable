🚨 Emergency Arrangement — New Slot-wise Timetable
Absent teachers (marked in the Absences tab) are left out, and all other available teachers are allotted to classes in new slots for the day. Priority: the teacher who already teaches that class, then subject/level match (PGT→senior, TGT→junior, Arts↔Arts, Science↔Science), then any free teacher.
1. Slot structure (how the 8 periods of the day are divided)
2. Exempt Teachers (present in school but should not be given duty in this arrangement)
3. Exempt Classes / Sections (classes/sections not available that day are left out of the timetable; also applies to the Absences tab)
4. Combine Sections (low attendance: merge A+B. The available teacher of either section takes both; if both are available the A-section teacher takes it and the other teacher becomes free; if neither is available a free teacher from other sections is used; also applies to the Absences tab)
🚨 Emergency Arrangement — Bulk / Mass Absence
When many teachers are absent, distribute all free periods equitably among available teachers. Choose how many periods per teacher, combine classes if needed.

💾 Auto-Save Status
All changes (timetable edits, teacher data, settings, logos) are automatically saved to this browser's storage on this specific PC — no Save button needed.

⚠️ Important: browser storage is tied to ONE browser on ONE PC. It will NOT show up if you open this file in a different browser (e.g. Chrome vs Edge) or a different computer — that is expected, not a bug. It can also be lost if the browser's data is cleared, the profile gets corrupted, or Windows crashes/loses power before a change is saved.

👉 To carry your data between browsers/PCs, or to protect against sudden power loss, use "Download Backup File" below regularly (e.g. daily, or right after any big change) and keep the file safe (pen drive / cloud / email to yourself). If anything ever goes wrong, use "Restore from Backup File" to bring everything back — in any browser, on any PC.
